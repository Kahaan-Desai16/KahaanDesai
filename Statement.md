# Problem Statement

Calculating the area of different shapes seperately can take some time, especially when the user has to use different formulas for each shape .
This project is made is made to provide a simple way to calculate the area of common shapes using one program.
The program allows the user to choose a shape from a menu and eter the required dimensions. It then calculates and displays the area of the 
selected shape . The program also allows the user to calculate the area of another shape without having to restart the program.

# Scope of the project

The project is mainly focused on calculating the area of four basic shapes; Square,Rectangle,circle and triangle. The program takes required 
dimensions from the user and uses appropriate mathematical formulas to calculate the area. This project can be improved by adding more shapes
allowing decimal values and providing more options to the user

# Target User

This program can be used by student and other users who need to calculate the area of absic geometric shapes. It can also be useful for beginners
who are learning Python and want to understand concepts such as functions, user inputs, conditional statements and loops

# High-Level Features

- Menu-driven interface
- Calculates the area of square, rectangle , circle and triangle
- Takes user input for dimensions
- Allows user to calculate the area of multiple shapes without restarting the program
- Simple command line interface with no external dependencies
