# Shape area calculator

This is a simple program that helps the user calculate the area of different shapes like square, rectangle,cirle,triangle based on the input given by the user.The program runs till the user wants


# Features
1.Menu Driven Interface
2.Gives the option to calculate the area of multiple shapes without restarting the program
3. Gives area for many shapes


# Prerequisite
--> Python 3.x should be installed on your system


# Setup

1. Clone this repository:
```bash
git clone https://github.com/Kahaan-Desai16/KahaanDesai.git
```

2. Navigate into project folder
```bash
cd KahaanDesai
```


# Depedencies
No external dependencies or libraries are required — the project only uses Python's built-in `input()` and `print()` functions.


# How to run

Run the script from the terminal

```bash
python area_calculation.py
```

# Usage

1. When the program starts you see a menu:

```
WELCOME
please make a choice from the below listed shapes
1.square
2.rectangle
3.circle
4.triangle
```

2.You have to enter the number corresponding to your shape(1-4)

3. Enter the required dimensions of the shape as asked by the program

4.Area shall be displayed

5.You will be asked if you want to continue
	a. If you enter 'y' then the program runs again
	b. If you enter 'n' then the program ends and prints "Thank You"
